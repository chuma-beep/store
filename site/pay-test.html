How It Works

  1. User clicks Buy button
  2. If no wallet installed, shows install options (Phantom, Solflare, Backpack)
  3. If multiple wallets, user picks which one to use
  4. Wallet popup asks user to approve the transaction
  5. ONE transaction sends:
    • $4.50 (90%) → Developer's wallet
    • $0.50 (10%) → Store wallet
  6. Transaction confirmed on Solana (~400ms)
  7. User gets download access
