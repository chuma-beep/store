NetNeighbors plugin for Omarchy

by i12bp8 · Unverified

Fing-style Wi-Fi radar for the bar: one click shows every device on your network — vendor, hostname, MAC — and flags new ones that appear.

How to add NetNeighbors

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/i12bp8/omarchy-netneighbours.git --enable

To remove it later, run omarchy plugin remove io.github.i12bp8.netneighbors. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
