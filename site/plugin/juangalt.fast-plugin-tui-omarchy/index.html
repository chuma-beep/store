Fast Plugin TUI for Omarchy plugin for Omarchy

by Juan Galt · Verified

Browse, search, sort and install Omarchy marketplace plugins from a fzf TUI

How to add Fast Plugin TUI for Omarchy

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/juangalt/fast-plugin-tui-omarchy.git --enable

To remove it later, run omarchy plugin remove juangalt.fast-plugin-tui-omarchy. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
