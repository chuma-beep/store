BW Vault plugin for Omarchy

by keboy · Verified

Bitwarden vault in the Omarchy bar, powered by the bw CLI. A dropdown that searches your vault and copies a password without leaving the window you're pasting into, over a shared session that survives between opens.

How to add BW Vault

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/alkevintan/bw-vault.git --enable

To remove it later, run omarchy plugin remove com.aktivesolutions.bw-vault. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
