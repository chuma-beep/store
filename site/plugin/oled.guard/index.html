OLED Guard plugin for Omarchy

by rawritude · Verified

Attenuates the always-on status bar strip so it stops out-wearing the rest of your OLED panel, and clears the moment you point at it.

How to add OLED Guard

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/rawritude/omarchy-oled-guard.git --enable

To remove it later, run omarchy plugin remove oled.guard. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
