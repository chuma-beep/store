OmaGlimpse plugin for Omarchy

by TammyX44 · Verified

Theme-aware desktop widgets for Omarchy with system stats, battery and power profiles, media controls, processes, disks, network speed, and temperatures.

How to add OmaGlimpse

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/TammyX44/OmaGlimpse.git --enable

To remove it later, run omarchy plugin remove io.github.tammyx44.omaglimpse. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
