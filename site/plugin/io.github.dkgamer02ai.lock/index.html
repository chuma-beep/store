Nova Lock plugin for Omarchy

by dkg · Unverified

Quickshell session lock with a split two-tone clock, profile picture and pill password field.

How to add Nova Lock

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/dkgamer02ai/nova-lock.git --enable

To remove it later, run omarchy plugin remove io.github.dkgamer02ai.lock. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
