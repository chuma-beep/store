Bose plugin for Omarchy

by Andres Riveros · Verified

Bose QuietComfort battery, mode, noise-control, and equalizer panel

How to add Bose

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/andresantonioriveros/omarchy-bose.git --enable

To remove it later, run omarchy plugin remove io.github.andresariveros.omabose. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
