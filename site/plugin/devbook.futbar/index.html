FutBar plugin for Omarchy

by devbook · Unverified

Live match center and football tracker with tactical lineups, real-time scores, standings, and live event alerts.

How to add FutBar

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/AlwaysRead/omarchy-futbar-plugin.git --enable

To remove it later, run omarchy plugin remove devbook.futbar. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
