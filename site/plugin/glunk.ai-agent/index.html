AI Agent Assistant plugin for Omarchy

by Glunk · Verified

Your AI agent assistant widget for the Omarchy status bar, sitting right next to screen time.

How to add AI Agent Assistant

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/glunk660/omarchy-ai-agent.git --enable

To remove it later, run omarchy plugin remove glunk.ai-agent. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
