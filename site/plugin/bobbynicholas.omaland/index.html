Omaland plugin for Omarchy

by Bobby Nicholas · Unverified

A panel for editing Hyprland's visual look and feel, with live preview. Writes a managed block into ~/.config/hypr/looknfeel.lua. Open from the Omarchy menu by searching 'Omaland' or from the terminal with: omarchy-shell shell toggle bobby…

How to add Omaland

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/bobby-nicholas/omaland.git --enable

To remove it later, run omarchy plugin remove bobbynicholas.omaland. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
