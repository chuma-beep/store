Drives plugin for Omarchy

by AR Singh · Verified

All drives in the Omarchy bar: a single icon opens a popup with every disk, mounted or not — click unmounted to mount, click mounted to open, press 't' to open in terminal, click ✕ button to unmount, ⏏ to eject (power-off) removable drives.

How to add Drives

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/arsinghin/drives.git --enable

To remove it later, run omarchy plugin remove drives. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
