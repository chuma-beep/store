OmaMigrate plugin for Omarchy

by luneth90 · Verified

Portable Omarchy migration backups for applications, AI developer credentials, proxy services, user configurations, and system dotfiles.

How to add OmaMigrate

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/luneth90/omamigrate.git --enable

To remove it later, run omarchy plugin remove luneth90.omamigrate. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
