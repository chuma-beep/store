Input Methods plugin for Omarchy

by Masaki Komagata · Verified

Fcitx 5 input-method indicator and switcher

How to add Input Methods

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/komagata/omarchy-input-method.git --enable

To remove it later, run omarchy plugin remove komagata.input-method. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
