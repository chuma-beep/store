How to add Pokey — Make them SEE it

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/pixeye33/omarchy-pokey.git --enable

To remove it later, run omarchy plugin remove pixeye.pokey. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
