Shan Shui plugin for Omarchy

by ZeD · Verified

An endless Chinese landscape scroll painted on your desktop, stroke by stroke, left to right, in your theme's colors. Built on LingDong-'s {Shan, Shui}*. The drawing happens outside the shell at low priority; on screen it is one small shad…

How to add Shan Shui

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/zednaked/omarchy-shanshui.git --enable

To remove it later, run omarchy plugin remove zed.shanshui. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
