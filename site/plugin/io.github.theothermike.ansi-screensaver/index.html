ANSI Screensaver plugin for Omarchy

by Mike · Verified

ANSI/ASCII art slideshow screensaver with ttfx reveals, a library gallery, online art sources, and idle takeover.

How to add ANSI Screensaver

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/theothermike/omarchy-ansi-screensaver.git --enable

To remove it later, run omarchy plugin remove io.github.theothermike.ansi-screensaver. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
