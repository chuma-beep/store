Omarchy Phone plugin for Omarchy

by Adam Moussa Ali · Unverified

Ruby-powered Android control and iPhone AirPlay mirroring for Omarchy.

How to add Omarchy Phone

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/AdamMusa/omarchy-phone.git --enable

To remove it later, run omarchy plugin remove izeesoft.omarchy-phone. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
