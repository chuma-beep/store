AI Usage plugin for Omarchy

by AkitaOnRails · Unverified

Multi-provider AI plan usage and balances in a native Omarchy Quattro panel. Needs the ai-usagebar binary as well as this plugin: omarchy pkg aur add ai-usagebar-bin

How to add AI Usage

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/akitaonrails/ai-usagebar.git --enable

To remove it later, run omarchy plugin remove akitaonrails.ai-usagebar. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.

Source: github.com/akitaonrails/ai-usagebar
