OmaValet plugin for Omarchy

by Scott Angel · Unverified

Park and assign apps to Omarchy workspaces without editing Lua. Starts in the bar for quick setup, then switches between bar and Omarchy command-menu access from inside OmaValet. A parked app follows its workspace when opened. Optional log…

How to add OmaValet

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/jcarcinogen/OmaValet.git --enable

To remove it later, run omarchy plugin remove io.github.jcarcinogen.omavalet. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
