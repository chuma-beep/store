Touchpad Edge Controls plugin for Omarchy

by OmAjitJadhav · Verified

Dual-edge vertical swipe sliders for laptop touchpads on Omarchy. Right edge swipes adjust system volume; left edge swipes adjust display brightness with native Omarchy OSD feedback. Features intelligent palm rejection, multi-touch bypass,…

How to add Touchpad Edge Controls

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/OmAjitJadhav/omarchy-touchpad-edge.git --enable

To remove it later, run omarchy plugin remove omajitjadhav.touchpad-edge. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
