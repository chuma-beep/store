Attention plugin for Omarchy

by Ayan De · Verified

Privacy shield: the screen blurs when you look away from it and clears when you look back, driven by the glanced daemon's head-pose stream. No screen capture, no input grabbing, fails open.

How to add Attention

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/ayandexyz/omarchy-attention.git --enable

To remove it later, run omarchy plugin remove io.github.ayandexyz.attention. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
