Den plugin for Omarchy

by Saif · Unverified

Windows-style overflow flyout: tuck away tray apps and bar plugins behind one chevron

How to add Den

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/SaifOmar/so.den.git --enable

To remove it later, run omarchy plugin remove so.den. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
