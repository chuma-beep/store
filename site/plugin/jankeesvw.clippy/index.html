Clippy plugin for Omarchy

by Jankees van Woezik · Unverified

A paperclip in the corner of your screen that watches your mouse and hands out tips from the Omarchy manual.

How to add Clippy

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/jankeesvw/omarchy-clippy.git --enable

To remove it later, run omarchy plugin remove jankeesvw.clippy. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
