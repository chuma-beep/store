GitHub repo search plugin for Omarchy

by EmiiFont · Unverified

Fuzzy-search your GitHub repos and orgs; Enter opens in browser, Ctrl+Enter clones

How to add GitHub repo search

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/EmiiFont/omarchy-github-search.git --enable

To remove it later, run omarchy plugin remove emiifont.github-search. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
