Echo Shelf plugin for Omarchy

by Joan Subirats · Verified

A focused Overview, Music, and Firmware panel for the Snowsky Echo Mini.

How to add Echo Shelf

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/subirats345/echo-shelf.git --enable

To remove it later, run omarchy plugin remove io.github.subirats345.echo-shelf. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
