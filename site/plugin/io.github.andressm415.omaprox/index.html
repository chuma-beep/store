Omaprox plugin for Omarchy

by AndresSM415 · Verified

Read-only Proxmox VE dashboard in the Omarchy bar: every container and VM with a status LED, per-guest stats, and one key to a console.

How to add Omaprox

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/AndresSM415/omaprox.git --enable

To remove it later, run omarchy plugin remove io.github.andressm415.omaprox. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
