Darky plugin for Omarchy

by mehiel · Verified

Switch your Omarchy theme and wallpaper with the sun. Pick a theme and background for day and for night, follow sunrise and sunset for a city, or set your own times.

How to add Darky

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/mehiel/mehiel.darky.git --enable

To remove it later, run omarchy plugin remove mehiel.darky. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
