VoxClaude plugin for Omarchy

by hydrox · Verified

Hold a key, say what you want, and Claude Code does it in the background. A terminal opens only when you ask for one or Claude needs you.

How to add VoxClaude

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/NimbleAINinja/omarchy-voxclaude.git --enable

To remove it later, run omarchy plugin remove io.github.nimbleaininja.voxclaude. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
