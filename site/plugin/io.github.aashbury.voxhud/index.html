Voxhud plugin for Omarchy

by aashbury · Verified

A minimalist, theme-aware HUD for Voxtype dictation: listening, processing, done - with the real keys to stop, a click to cancel, and your dictionary one click away in the bar.

How to add Voxhud

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/aashbury/voxhud.git --enable

To remove it later, run omarchy plugin remove io.github.aashbury.voxhud. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
