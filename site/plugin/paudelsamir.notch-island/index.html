Notch Island plugin for Omarchy

by paudelsamir · Unverified

An edge-anchored notch / pill that rests as an app dock, clock, headlines, weather or quick notes, becomes a media island while music plays, and pops up volume, brightness, now playing, opencode and power.

How to add Notch Island

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/paudelsamir/notch-island.git --enable

To remove it later, run omarchy plugin remove paudelsamir.notch-island. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
