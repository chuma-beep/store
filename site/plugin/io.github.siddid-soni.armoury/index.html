Armoury plugin for Omarchy

by Siddid Soni · Verified

ASUS ROG control for Omarchy: performance modes, fan curves, power limits, lighting (with a music effect), battery, display, GPU, NumberPad and Keystone. Needs its armouryd daemon: run install.sh from the plugin folder once.

Setup

This plugin requires additional setup before it can be enabled. Follow the upstream installation instructions.
