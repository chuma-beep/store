NetBird plugin for Omarchy

by Nico Kovacs · Verified

NetBird status, connection toggling, peer browsing, exit node selection, SSH into peers, and quick copy actions in the Omarchy bar.

How to add NetBird

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/nico-kovacs/omarchy-plugin-netbird.git --enable

To remove it later, run omarchy plugin remove io.github.nico-kovacs.netbird. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
