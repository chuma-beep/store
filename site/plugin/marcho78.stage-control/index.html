Stage Control plugin for Omarchy

by marcho78 · Verified

Organize your desktops from one view. Swipe up with four fingers (or press Super+A) and every window steps onto the stage as a live preview, under a bar of all your desktops with live thumbnails. Drag windows onto any desktop; add, remove,…

How to add Stage Control

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/marcho78/omarchy-stage-control.git --enable

To remove it later, run omarchy plugin remove marcho78.stage-control. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
