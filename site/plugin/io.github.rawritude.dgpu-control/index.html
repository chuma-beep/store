dGPU Control plugin for Omarchy

by rawritude · Unverified

Control the discrete GPU on a dual-GPU machine: block it entirely, allow it per-application, or leave it to park itself — and see exactly which processes are keeping it awake. Reads never wake the card. Optional ASUS ROG/TUF power profile…
