Proton Drives plugin for Omarchy

by Spencer Owen · Unverified

Native Proton Drive sync for multiple accounts: bar status, storage usage, and pause/resume, backed by rclone mounts.

How to add Proton Drives

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/spuder/omarchy-protondrives.git --enable

To remove it later, run omarchy plugin remove spuder.protondrive. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.

Source: github.com/spuder/omarchy-protondrives
