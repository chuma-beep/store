Agent Orchestrator plugin for Omarchy

by meviusisback · Verified

Live monitor and workspace orchestrator for AI coding agents (Herdr, OMP, Hermes, remote Hermes peers, Claude, Codex, Grok) in the Omarchy bar.

How to add Agent Orchestrator

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/meviusisback/agent-orchestr.git --enable

To remove it later, run omarchy plugin remove meviusisback.agent-orchestr. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
