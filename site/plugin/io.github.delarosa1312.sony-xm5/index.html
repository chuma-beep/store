Sony XM5 plugin for Omarchy

by delarosa1312 · Unverified

Battery, noise control and equaliser for the Sony WH-1000XM5 and WF-1000XM5. Also needs the mdrctl daemon from the same repository: a bar widget cannot hold a Bluetooth control session on its own. Installing the widget alone is safe -- it…

How to add Sony XM5

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/delarosa1312/omarchy-sony-xm5.git --enable

To remove it later, run omarchy plugin remove io.github.delarosa1312.sony-xm5. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
