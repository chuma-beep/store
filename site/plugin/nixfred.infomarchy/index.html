Infomarchy plugin for Omarchy

by Fred Nix & Larry · Unverified

A live, clickable wallpaper desk for AI sessions, proactive next-action alerts, repository health, Ollama controls, activity, usage limits, and machine telemetry. Theme-driven. SUPER+D overlay. Optional Web Mode.
