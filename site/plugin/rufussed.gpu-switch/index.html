GPU Selecta plugin for Omarchy

by rufussed · Unverified

Global and per-app GPU renderer switching for multi-GPU systems (AMD, Intel, NVIDIA), via PRIME render offload.

How to add GPU Selecta

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Rufussed/gpu-selecta.git --enable

To remove it later, run omarchy plugin remove rufussed.gpu-switch. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
