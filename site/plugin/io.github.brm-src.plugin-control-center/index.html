Plugin Control Center plugin for Omarchy

by Cris / brm-src · Unverified

See every installed Omarchy plugin, enable or disable them, edit their bar settings, and uninstall third-party ones, from one compact panel.

How to add Plugin Control Center

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/brm-src/plugin-control-center.git --enable

To remove it later, run omarchy plugin remove io.github.brm-src.plugin-control-center. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
