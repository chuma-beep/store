Rocketlauncher plugin for Omarchy

by Harris Kenny · Verified

See the next space launch without leaving Omarchy. Countdown, flip-digit Falcon & Starship stats, Watch. Unofficial; The Space Devs (LL2). Not affiliated.

How to add Rocketlauncher

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/kenhara/omarchy-rocketlauncher.git --enable

To remove it later, run omarchy plugin remove kenhara.rocketlauncher. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
