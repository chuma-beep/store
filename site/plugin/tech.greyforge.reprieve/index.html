Reprieve plugin for Omarchy

by Greyforge Labs · Unverified

A safety net for Super+W on Omarchy: the window is hidden, not terminated, and one keystroke returns it exactly as it was. Survives shell restarts.

How to add Reprieve

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/GreyforgeLabs/reprieve.git --enable

To remove it later, run omarchy plugin remove tech.greyforge.reprieve. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.

Source: github.com/GreyforgeLabs/reprieve
