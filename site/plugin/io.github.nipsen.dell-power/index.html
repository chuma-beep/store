Dell Power plugin for Omarchy

by NIPSEN · Verified

Battery, Dell and Alienware charge limit, thermal modes, fans, power profile, and system stats

How to add Dell Power

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/NIPSEN/omarchy-dell-power.git --enable

To remove it later, run omarchy plugin remove io.github.nipsen.dell-power. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
