Open Notebook Studio plugin for Omarchy

by Dean Waters · Verified

Capture, search, chat, and turn your Open Notebook knowledge base into podcasts from the Omarchy bar

How to add Open Notebook Studio

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/dlpwaters/omarchy-open-notebook.git --enable

To remove it later, run omarchy plugin remove io.github.dlpwaters.open-notebook. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
