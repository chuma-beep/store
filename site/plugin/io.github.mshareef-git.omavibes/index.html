OmaVibes plugin for Omarchy

by Mohammed Shareef · Verified

Cozy typing sound effects with over 40+ sounds, gamified typing stats with ranks, detailed analytics, random playback, and volume control for the Omarchy bar.

How to add OmaVibes

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/mshareef-git/omavibes.git --enable

To remove it later, run omarchy plugin remove io.github.mshareef-git.omavibes. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
