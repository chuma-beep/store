Display Scanlines plugin for Omarchy

by Ty Richards · Unverified

Display controls with integer-locked, resolution-aware CRT scanline presets

How to add Display Scanlines

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/TyRichards/omarchy-display-scanlines.git --enable

To remove it later, run omarchy plugin remove io.github.tyrichards.display-scanlines. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
