Pixel Buds plugin for Omarchy

by Ryan Doupe · Verified

Pixel Buds Pro in the Omarchy bar: battery per bud and case, listening modes, shared volume with swipe OSD, touch gestures, and device + sound controls (multipoint, speech detection, EQ, balance). Event-driven: the icon appears the moment…

How to add Pixel Buds

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/rdoupe/omarchy-pixelbuds.git --enable

To remove it later, run omarchy plugin remove io.github.rdoupe.pixelbuds. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
