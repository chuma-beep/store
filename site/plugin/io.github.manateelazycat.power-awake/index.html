Omarchy Power Awake plugin for Omarchy

by ManateeLazyCat · Verified

Keeps desktops awake and manages laptop idle behavior based on the power source.

How to add Omarchy Power Awake

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/manateelazycat/omarchy-power-awake.git --enable

To remove it later, run omarchy plugin remove io.github.manateelazycat.power-awake. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
