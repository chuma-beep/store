Prisma plugin for Omarchy

by diogocezar · Verified

Control the RGB lighting of your whole PC (motherboard, RAM, graphics card, fans, keyboard, mouse) from one icon in the Omarchy bar: one color for everything, a color per device, or your theme's colors. Powered by OpenRGB.

Setup

This plugin requires additional setup before it can be enabled. Follow the upstream installation instructions.
