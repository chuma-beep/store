Tasks & Time Tracker plugin for Omarchy

by Sheikh Limon · Verified

Native task tracker, live stopwatch timer, and Markdown notes widget for the Omarchy bar

How to add Tasks & Time Tracker

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/sheikhlimon/omarchy-todo.git --enable

To remove it later, run omarchy plugin remove limon.todo. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
