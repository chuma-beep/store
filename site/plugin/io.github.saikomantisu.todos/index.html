Daily Todos plugin for Omarchy

by Saikomantisu · Verified

The Big 3 plus everyday todos, a Later list, a day progress bar, and a mascot that reacts to how the day is going

How to add Daily Todos

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Saikomantisu/omarchy-todos.git --enable

To remove it later, run omarchy plugin remove io.github.saikomantisu.todos. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
