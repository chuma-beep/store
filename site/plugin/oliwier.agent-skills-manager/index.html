How to add Agent Skills Manager

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/oliwier-xiao/agent-skills-manager.git --enable

To remove it later, run omarchy plugin remove oliwier.agent-skills-manager. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
