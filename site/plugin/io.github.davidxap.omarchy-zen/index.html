How to add Omarchy Zen Themes Sync

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Davidxap/omarchy-zen.git --enable

To remove it later, run omarchy plugin remove io.github.davidxap.omarchy-zen. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
