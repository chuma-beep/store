Parametric EQ plugin for Omarchy

by Prudhvi Yalamanchili · Verified

A full parametric PipeWire equalizer for Omarchy with live editing, headroom protection, presets, and AutoEQ import.

How to add Parametric EQ

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/prudhviy99/omarchy-parametric-eq.git --enable

To remove it later, run omarchy plugin remove io.github.prudhviy99.parametric-eq. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
