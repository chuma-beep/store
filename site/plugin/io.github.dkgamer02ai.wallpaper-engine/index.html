Wallpaper Engine plugin for Omarchy

by dkgamer02ai · Unverified

Use Steam Wallpaper Engine wallpapers as live Omarchy wallpapers. Adds menu > Style > Wallpaper Engine, which opens the thumbnail picker.

How to add Wallpaper Engine

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/dkgamer02ai/omarchy-wallpaper-engine.git --enable

To remove it later, run omarchy plugin remove io.github.dkgamer02ai.wallpaper-engine. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
