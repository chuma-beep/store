Mouse & Keybind Settings plugin for Omarchy

by davedes · Verified

Combined graphical configuration for mouse/pointer settings and Hyprland keybindings — cursor speed, acceleration profiles, scroll behavior, button remapping, synthetic button presses, battery indicator, and full keybind manager.

How to add Mouse & Keybind Settings

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Davedes83/mouse-keybind-plugin.git --enable

To remove it later, run omarchy plugin remove davedes.mouse-keybind-settings. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
