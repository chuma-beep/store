Omatop plugin for Omarchy

by Ryan Yogan · Verified

System monitor that shows you the culprit. Quiet bar glyph, live dot-matrix dropdown, full-screen diagnostic overlay with vim keys.

How to add Omatop

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/ryanyogan/omarchy-omatop.git --enable

To remove it later, run omarchy plugin remove ryanyogan.omatop. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
