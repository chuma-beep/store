Pane plugin for Omarchy

by bert · Verified

Weather on the inside of your screen: rain and snow that fall over your windows, droplets that bead up, merge and run down the glass, fog creeping in from the edges, and forked lightning in a storm

How to add Pane

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Bert0424/omarchy-pane.git --enable

To remove it later, run omarchy plugin remove bert.pane. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
