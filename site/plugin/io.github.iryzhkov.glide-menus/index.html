Glide menus plugin for Omarchy

by Igor Ryzhkov · Unverified

Cantina's cascading context menus reworked around clean, centered motion: the pane in use stays mid-screen, ghost panes preview submenus before you enter, the selection glides between rows, and typing searches the whole menu tree.

How to add Glide menus

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/iryzhkov/omarchy-glide-menus.git --enable

To remove it later, run omarchy plugin remove io.github.iryzhkov.glide-menus. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
