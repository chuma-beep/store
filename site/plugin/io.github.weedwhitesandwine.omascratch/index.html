Omascratch plugin for Omarchy

by weedwhitesandwine · Verified

A quick-note scratchpad that docks to a screen corner. Toggle with a keybind or the bar icon; font size, corner, and the keybind itself are all configurable from an in-panel settings view. Summon with: omarchy-shell shell toggle io.github.…

How to add Omascratch

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/weedwhitesandwine/omascratch.git --enable

To remove it later, run omarchy plugin remove io.github.weedwhitesandwine.omascratch. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
