Omarchy Pulse plugin for Omarchy

by Emre Can Yılmaz · Verified

Ambient presence for Omarchy: how many of us are here right now, by area, country and world. No account, no profiles, no chat.

How to add Omarchy Pulse

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/ecylmz/omarchy-pulse.git --enable

To remove it later, run omarchy plugin remove ecylmz.omarchy-pulse. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
