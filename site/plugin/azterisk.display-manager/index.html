Display Manager plugin for Omarchy

by Azteriisk · Verified

Advanced display controls, dynamic multi-monitor discovery, extend vs duplicate/mirror modes, visual screen positioning, per-monitor rotation, and workspace management

How to add Display Manager

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Azteriisk/omarchy-display-manager.git --enable

To remove it later, run omarchy plugin remove azterisk.display-manager. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
