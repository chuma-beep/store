Yet Another Active Window plugin for Omarchy

by ncc · Verified

A lightweight browser-style window list for Omarchy with application icons, stable ordering, focused titles, marquee overflow, hover labels, native visual settings, and horizontal and vertical bar layout support.

How to add Yet Another Active Window

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/ncc001/yet-another-active-window.git --enable

To remove it later, run omarchy plugin remove ncc.yet-another-active-window. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
