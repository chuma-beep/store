PasteImage plugin for Omarchy

by rocha · Verified

Paste screenshots into AI coding agents running in your terminal. Makes SUPER+V send Ctrl+V when a terminal is focused and the clipboard holds an image, so Claude Code and other TUIs can attach it.

How to add PasteImage

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/matheusrrocha/omarchy-pasteimage.git --enable

To remove it later, run omarchy plugin remove rocha.pasteimage. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
