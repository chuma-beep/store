Audio Patchbay plugin for Omarchy

by devfrp · Verified

Sample-rate and bit-depth presets scoped to what your device supports, plus a visual virtual patchbay for routing PipeWire ports.

How to add Audio Patchbay

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/devfrp/omarchy-audio-pro.git --enable

To remove it later, run omarchy plugin remove devfrp.audio-patchbay. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
