UniFi plugin for Omarchy

by Jonny Heggheim · Verified

Watch your UniFi network from the Omarchy bar: access points, switches and gateways with their online state, the gateway's WAN graph and links, overall client counts, and a notification when a device drops.

How to add UniFi

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/hegjon/omarchy-unifi.git --enable

To remove it later, run omarchy plugin remove hegjon.unifi. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
