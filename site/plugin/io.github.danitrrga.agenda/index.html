Agenda plugin for Omarchy

by danitrrga · Verified

The calendar block running now and the next one in the bar, with the day and week agenda in a panel

How to add Agenda

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/danitrrga/omarchy-agenda.git --enable

To remove it later, run omarchy plugin remove io.github.danitrrga.agenda. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
