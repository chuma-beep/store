Window Close Buttons plugin for Omarchy

by axelfontaine · Verified

Adds close buttons to windows, enhancing usability and beginner-friendliness without sacrificing esthetics. Hover over a window's top-right corner and a small close button appears. Click it to close the window.

How to add Window Close Buttons

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/axelfontaine/omarchy-window-close-buttons.git --enable

To remove it later, run omarchy plugin remove axel.window-close-buttons. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
