Auto-Hide Status Bar plugin for Omarchy

by ChazPounder78 · Verified

Auto-hide the Omarchy status bar unless the pointer is over its edge. A bar icon toggles it and opens a menu with on/off, edge sensitivity, hide/show delay sliders and an optional animated hide/show.

How to add Auto-Hide Status Bar

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/ChazPounder78/Chaz-Auto-Hide-Statusbar.git --enable

To remove it later, run omarchy plugin remove chaz.bar-autohide. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
