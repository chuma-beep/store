Monitor Profiles plugin for Omarchy

by Stephen Schwarz · Unverified

Save named monitor layouts and switch between them: a drag-and-drop editor plus a keyboard-driven quick switcher, both as one native Omarchy panel.

How to add Monitor Profiles

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/steveandkureen/omarchy-monitor-profiles.git --enable

To remove it later, run omarchy plugin remove dev.shantzware.monitor-profiles. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
