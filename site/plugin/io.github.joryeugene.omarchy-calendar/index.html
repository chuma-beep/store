Flight Deck Calendar plugin for Omarchy

by Jory Eugene · Unverified

Google Calendar and Outlook in one Omarchy panel, read-only by default

How to add Flight Deck Calendar

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/joryeugene/omarchy-calendar.git --enable

To remove it later, run omarchy plugin remove io.github.joryeugene.omarchy-calendar. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
