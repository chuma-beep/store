Password Store plugin for Omarchy

by Jonny Heggheim · Unverified

pass, the standard unix password manager, as an Omarchy launcher: press a key, type to search your store, then copy or type a password, username or OTP code. Decryption and clipboard clearing are left to pass itself.

Setup

This plugin requires additional setup before it can be enabled. Follow the upstream installation instructions.
