Switcher plugin for Omarchy

by paudelsamir · Unverified

A Niri-inspired scrolling layout, workspace overview, window switcher (AltTab), and workspace cycling (SuperTab), all individually toggleable. Styled with your Omarchy theme.

How to add Switcher

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/paudelsamir/switcher.git --enable

To remove it later, run omarchy plugin remove paudelsamir.switcher. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
