Battery Limiter plugin for Omarchy

by alexdont · Verified

Cap your battery's charge level to extend its lifespan: set the kernel charge limit (60/80/100 or a custom value) from the bar, see battery health and cycle count. Every change is a single explicit polkit prompt — no daemons, no udev rules

How to add Battery Limiter

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/alexdont/battery-limiter.git --enable

To remove it later, run omarchy plugin remove io.github.alexdont.battery-limiter. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
