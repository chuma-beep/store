omaFrigate plugin for Omarchy

by luccast · Verified

Frigate cameras in the Omarchy bar. Latest stills, live camera view, and review Frigate alerts.

How to add omaFrigate

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/luccast/omafrigate.git --enable

To remove it later, run omarchy plugin remove io.github.luccast.frigate. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
