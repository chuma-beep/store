Roku Remote plugin for Omarchy

by Jalv13 · Unverified

A native Omarchy remote for Roku TVs and players on the local network.

How to add Roku Remote

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Jalv13/omarchy-roku-remote.git --enable

To remove it later, run omarchy plugin remove io.github.jalv13.roku. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
