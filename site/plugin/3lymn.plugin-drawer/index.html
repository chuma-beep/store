Collapse chosen bar plugins into a tray-style drawer. Grid and list views with drag-and-drop reordering and a live preview of each plugin's bar icon; the grid stretches to fill the drawer width and the drawer adapts to the screen. Hide/unh…

How to add Plugin Drawer

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/alyayman921/Omarchy-drawer.git --enable

To remove it later, run omarchy plugin remove 3lymn.plugin-drawer. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
