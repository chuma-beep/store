Cloudflare WARP plugin for Omarchy

by Rui Silva · Verified

Control Cloudflare WARP connection and DNS settings from a keyboard-driven Omarchy bar panel.

How to add Cloudflare WARP

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/rpots/omarchy-cloudflare-warp.git --enable

To remove it later, run omarchy plugin remove io.github.rui-pedro-silva.cloudflare-warp. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
