Omadates plugin for Omarchy

by Gabbe2312 · Unverified

Apple Calendar in your Omarchy bar. Dots on the days that have something, today's events under the month grid, and a click for the details. Syncs iCloud, any CalDAV server, and webcal subscriptions.

Setup

This plugin requires additional setup before it can be enabled. Follow the upstream installation instructions.
