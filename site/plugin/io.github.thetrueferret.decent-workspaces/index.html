Decent Workspaces plugin for Omarchy

by TheTrueFerret · Verified

Per-monitor workspace indicators: shows only workspaces with windows, with an app icon beside each workspace number

How to add Decent Workspaces

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/TheTrueFerret/omarchy-decent-workspaces.git --enable

To remove it later, run omarchy plugin remove io.github.thetrueferret.decent-workspaces. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
