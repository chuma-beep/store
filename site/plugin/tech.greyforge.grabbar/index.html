Grabbar plugin for Omarchy

by Greyforge Labs · Unverified

Familiar window controls for Omarchy: minimize, maximize, close, move and resize with the mouse, and a drawer that always brings a minimized window back.

This plugin requires additional setup before it can be enabled. Follow the upstream installation instructions.
