Omagen plugin for Omarchy

by Prettyletto · Unverified

Generate Omarchy themes from images

How to add Omagen

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/prettyletto/omagen.git --enable

To remove it later, run omarchy plugin remove pretty.omagen. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
