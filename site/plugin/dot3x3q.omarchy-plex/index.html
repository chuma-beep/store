Omarchy Plex plugin for Omarchy

by 3x3q · Unverified

A full Plex player for Omarchy: sidebar library browsing, detail pages, theater + minibar playback, picture-in-picture floaty mode, audio/subtitle track selection, and keyboard-first navigation throughout.

How to add Omarchy Plex

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/dot3x3q/omarchy-plex.git --enable

To remove it later, run omarchy plugin remove dot3x3q.omarchy-plex. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
