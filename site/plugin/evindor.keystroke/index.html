Keystroke plugin for Omarchy

by Arseniy Zarechnev · Unverified

A Raycast-style command palette that replaces the Omarchy menu, with voice, Codex and community extensions

How to add Keystroke

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/evindor/keystroke.git --enable

To remove it later, run omarchy plugin remove evindor.keystroke. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
