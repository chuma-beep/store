OVaxry plugin for Omarchy

by Roman Weisman · Verified

An advanced dating engine to help Vaxry find a girlfriend.

How to add OVaxry

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Roman-Weisman/ovaxry.git --enable

To remove it later, run omarchy plugin remove io.github.roman.ovaxry. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
