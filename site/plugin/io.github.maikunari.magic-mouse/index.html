Magic Mouse for Omarchy plugin for Omarchy

by Mike Sewell · Verified

Make an Apple Magic Mouse feel like a Mac: Apple's pointer curve, sane scrolling, momentum, gestures, battery in the bar and a settings popup

How to add Magic Mouse for Omarchy

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/maikunari/omarchy-magic-mouse.git --enable

To remove it later, run omarchy plugin remove io.github.maikunari.magic-mouse. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
