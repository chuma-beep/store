Tally Screen Time plugin for Omarchy

by lunanoir21 · Verified

Screen time for Omarchy — which apps you focus and for how long, against a daily goal: a pill on the screen edge, a card under it, and reports as PNG, PDF and interactive HTML.

How to add Tally Screen Time

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/lunanoir21/tally-omarchy.git --enable

To remove it later, run omarchy plugin remove io.github.lunanoir21.tally-screentime. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
