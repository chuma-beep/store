Laser plugin for Omarchy

by Yasser · Verified

Laser focus for Omarchy. Tell it what you're working on; it notices when you drift and pulls you back. Classified by TypeSafe Jev with your own API key, privacy-first.

How to add Laser

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/iYassr/omarchy-laser.git --enable

To remove it later, run omarchy plugin remove yasserdo.laser. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
