Udder plugin for Omarchy

by stappmus · Unverified

See all your Herdr agents from the Omarchy bar, get notified when one finishes while you are away, and jump straight back to it.

How to add Udder

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/stappmus/Udder.git --enable

To remove it later, run omarchy plugin remove stappmus.udder. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
