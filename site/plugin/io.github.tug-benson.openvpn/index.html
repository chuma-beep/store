Omarchy OpenVPN Connect plugin for Omarchy

by tug-benson · Verified

OpenVPN client for Omarchy — multi-profile .ovpn import, username/password + TOTP (MFA) challenge/response auth, live tunnel traffic graph, and full network info (IP, gateway, DNS, routes, search domains).

How to add Omarchy OpenVPN Connect

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/tug-benson/omarchy-openvpn.git --enable

To remove it later, run omarchy plugin remove io.github.tug-benson.openvpn. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
