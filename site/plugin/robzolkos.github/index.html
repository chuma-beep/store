GitHub plugin for Omarchy

by Rob Zolkos · Unverified

A keyboard-friendly GitHub inbox for notifications, reviews, your own pull requests, assigned issues, Actions, and repositories.

How to add GitHub

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/robzolkos/omarchy-github.git --enable

To remove it later, run omarchy plugin remove robzolkos.github. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
