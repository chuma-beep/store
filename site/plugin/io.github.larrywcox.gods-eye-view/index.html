God's Eye View plugin for Omarchy

by Omarchy Community · Verified

Install, launch, and manage God's Eye View from the Omarchy bar.

How to add God's Eye View

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/larrywcox/omarchy-gods-eye-view.git --enable

To remove it later, run omarchy plugin remove io.github.larrywcox.gods-eye-view. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
