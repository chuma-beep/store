Ambience plugin for Omarchy

by Dorneles · Unverified

Offline ambient soundscapes, procedural noise generator, and focus sound studio for Omarchy.

How to add Ambience

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/jvlianodorneles/ambience.git --enable

To remove it later, run omarchy plugin remove dorneles.ambience. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
