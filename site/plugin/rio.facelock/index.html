Omarchy Biometrics Suite (Face ID & Fingerprint) plugin for Omarchy

by Harsh Joshi · Verified

High-accuracy AI Face Unlock & Fingerprint biometrics for Omarchy Linux with animated visual radar, SDDM greeter, sudo, and lock screen support.

How to add Omarchy Biometrics Suite (Face ID & Fingerprint)

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/harshjsh01/rio.facelock.git --enable

To remove it later, run omarchy plugin remove rio.facelock. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
