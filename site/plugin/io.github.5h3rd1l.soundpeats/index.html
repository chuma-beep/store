Omapeats plugin for Omarchy

by 5h3rd1l · Verified

SoundPEATS earbud noise control (Off / ANC / Transparency), game mode, and per-bud battery in the Omarchy bar.

How to add Omapeats

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/5h3rd1l/omapeats.git --enable

To remove it later, run omarchy plugin remove io.github.5h3rd1l.soundpeats. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
