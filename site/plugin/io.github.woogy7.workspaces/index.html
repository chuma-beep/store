Workspace Switcher plugin for Omarchy

by Woogy7 · Verified

Alt-tab for workspaces: a calm ribbon or carousel of live workspace previews. Hold Super, tap Tab to cycle, release to switch.

How to add Workspace Switcher

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/Woogy7/omarchy-workspace-switcher.git --enable

To remove it later, run omarchy plugin remove io.github.woogy7.workspaces. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
