Vercel plugin for Omarchy

by Wesley Cole · Unverified

Vercel projects and deployments in the Omarchy bar using your existing CLI login.

How to add Vercel

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/wesleycole/omarchy-vercel.git --enable

To remove it later, run omarchy plugin remove io.github.wesleycole.vercel. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
