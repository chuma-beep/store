Switch Magic plugin for Omarchy

by Renan Tonheiro (@renanmt) · Verified

A visual workspace and window switcher with customizable shortcuts, layouts, and live previews.

How to add Switch Magic

Click GET in the Omarchy Store desktop app, or run:

omarchy plugin add https://github.com/renanmt/switch-magic.git --enable

To remove it later, run omarchy plugin remove renanmt.switch-magic. Verified means it passed the marketplace's automated security check for the listed version; plugins are made by independent developers, so only add ones you trust.
