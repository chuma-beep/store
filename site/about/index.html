About Omarchy Store

Omarchy Store is the world's largest app store for Omarchy Linux. We make it easy to discover, install, update and remove apps, themes, plugins and screensavers — all in one click, no terminal required.

What is Omarchy?

Omarchy is a beautiful, fast and agentic Linux distribution created by DHH (David Heinemeier Hansson). It's built on Arch Linux with the Hyprland tiling window manager, designed to be keyboard-first and AI-native. Omarchy makes Linux accessible and gorgeous out of the box.

Learn more at omarchy.com or read the Omarchy Manual.

What Omarchy Store Offers

  • Omarchy Apps — The full library of Linux applications, from browsers to developer tools to games
  • Omarchy Themes — Desktop themes that transform your terminal, bar, launcher and wallpaper
  • Omarchy Plugins — Bar widgets and desktop add-ons from the community
  • Screensavers — Idle animations and lock screen effects
  • Get Omarchy — Download and install Omarchy Linux

How It Works

  1. Get the Omarchy Store desktop app (pre-installed on Omarchy 4)
  2. Browse or search for what you want
  3. Press GET — it installs automatically
  4. Press UPDATE when new versions arrive
  5. Press REMOVE when you're done

No terminal commands needed. Everything is verified and safe.

Security

Every app in Omarchy Store is verified before listing:

  • Apps install from official Arch repositories, the AUR (community-maintained), or verified developer releases
  • Plugins are checked by the Omarchy Plugin Marketplace's automated security scanner
  • Themes only change colors and wallpapers — they can't run code
  • The store never executes code from web pages — it only calls your system package manager

Who Makes Omarchy Store?

Omarchy Store is built by Omarchy Development Labs, an independent developer creating tools for the Omarchy community. We're not affiliated with 37signals or the official Omarchy team, but we share the same goal: making Linux beautiful and accessible.
