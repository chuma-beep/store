Get Omarchy

Omarchy is a free, fast and beautiful Linux desktop made by DHH. Install it in about 15 minutes.

1. Make the installer USB

Download the latest Omarchy ISO, then write it to an 8 GB+ USB stick with Rufus (Windows), balenaEtcher (Windows and Mac) or Ignite in the Omarchy Store.

2. Replace Windows or keep it

Use the whole drive, or shrink Windows in Disk Management and choose Free space install to dual boot.

3. Install

Boot from the USB (F12, F11, F8 or Esc), turn off Secure Boot if needed, and answer a few questions.

4. Get the Omarchy Store

curl -fsSL https://omarchystore.com/install.sh | bash
