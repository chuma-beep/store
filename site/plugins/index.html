Plugins for Omarchy Linux

The world's largest list of community plugins for Omarchy Linux: bar widgets, system tools, productivity add-ons and more, each marked Verified or…

Plugin listings courtesy of the Omarchy Plugin Marketplace.

How to add an Omarchy plugin

  1. Click GET in the Omarchy Store desktop app, or run omarchy plugin add <git-url> --enable in a terminal.
  2. See what you have with omarchy plugin list.
  3. Remove one any time with omarchy plugin remove <id>.
